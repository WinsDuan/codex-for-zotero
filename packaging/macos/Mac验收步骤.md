# Mac 验收步骤 · 0.6.6

请在真实 Mac 上执行下面项目。使用一个新建的测试对话和测试目录，完成后可以自行清理。建议至少由 Apple Silicon、Intel 各一位用户验收；记录 macOS、Zotero、Codex 版本与架构，不共享登录凭据。

| 项目 | 操作 | 通过标准 |
| --- | --- | --- |
| 1. 安装 | 安装 XPI，⌘Q 后重开 | 插件列表显示 0.6.6，其他插件仍在 |
| 2. 入口 | 点顶部研桥，关闭后再按 ⌘⌥C | 两种入口都可打开，切换论文不抢占其他面板 |
| 3. 连接 | 程序路径留空，点重连 | 显示已连接，模型列表可选 |
| 4. 简单对话 | 发送“只回复：Mac连接成功” | 实际收到模型回复，无发送错误 |
| 5. 工作区 | 在文稿中新建测试目录，关闭再打开 Zotero | 对话、保存路径与历史保持完整 |
| 6. 中文与空格路径 | 工作区使用“研桥验收 With Spaces” | 文件导入、产物打开、重开历史均正常 |
| 7. PDF 图文 | 读第一页文字和图片，再核对 research_pdf_status | 真实工具返回 1 页文字、1 页图像，不能把全文记为已读 |
| 8. 图表 | 指定真实含图页面提问 | 阅读依据含对应页的图像，回答与图的内容可核对 |
| 9. 图片 | 添加 PNG/JPG 提问，点击预览 | 图片可发送、放大、平移、导出 |
| 10. 排版与复制 | 输出 Markdown 表格、LaTeX 公式，鼠标选中 ⌘C | 表格、公式排版，复制得到对应内容 |
| 11. 文件 | 允许当前工作区工具，生成 artifacts/test.md | 文件卡可打开，定位能在 Finder 找到 |
| 12. 编辑 | 编辑一条已发送消息后重新生成 | 新版本继续，原版本内容仍保留 |
| 13. 清理与撤销 | 只选测试产物移入废纸篓，再撤销 | 文件消失后恢复，正文和论文原件不变 |
| 14. 本地 Skill | 读取 Skill 列表，选一个自己已安装的技能运行 | 技能被实际调用，输出在当前工作区；工具进度可核对 |
| 15. 重启恢复 | ⌘Q 再开，继续同一条对话 | 入口、连接、历史可恢复，无需重新填路径 |
| 16. 外置盘（若使用） | 在常用磁盘测试导入、产物与清理 | 权限明确；清理失败不会转为永久删除 |

验收结论应分别写“通过 / 失败 / 未测”，不能把未测项写为通过。图片生成取决于账号实际能力，若服务没有提供生图工具，记录为能力不可用，而不是假装生成成功。

## 开发者自动检查

在源码目录运行（需自行安装 Node.js 22 与 Python 3.10+）：

```zsh
node --test tests/*.test.cjs
python3 packaging/build_xpi.py
python3 packaging/build_macos_release.py
```

Mac 上 `tests/macos-native.test.cjs` 会在新建临时目录内实际测试废纸篓往返、符号链接拦截、目录边界和不覆盖原文件；其他系统跳过这一项。GitHub Actions 在 `macos-14`、`macos-15-intel` 与 Windows 上执行。自动检查不登录用户账号，不调用付费模型，也不替代上述图形界面验收。
