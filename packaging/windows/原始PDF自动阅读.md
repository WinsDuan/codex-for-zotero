# 原始 PDF 自动阅读 · 0.6.5

## 怎样使用

1. 在 Zotero 打开论文的本地 PDF，再打开研桥；首次使用先选择此对话保存位置。
2. 设置中默认开启「自动读取原始 PDF（正文与图表）」。无需先截图，也无需勾选「预载文字」。
3. 直接提问：「结合全文总结方法和局限」「解释图 3 的坐标、曲线和结论」「比较这两篇论文的实验图表」。
4. Codex 可以调用内置工具列出原始 PDF、查找图注/关键词、读取指定页面文字和页面图像。遇到扫描页也可请求页面图像。
5. 回答下方的「PDF 阅读依据」列出工具实际返回的物理页、印刷页标签和是否包含图像。点击记录可回到 Zotero 中的对应页面；外部导入 PDF 会用系统阅读器打开原文件副本。

「预载文字」是提前发送文字索引的选项。关闭它仍可以按需读取原 PDF；如需只根据现有摘要、笔记或图片回答，在设置中关闭「自动读取原始 PDF」。

## 文件如何接入

- 优先使用当前阅读器打开的本地 PDF；在文献库使用时，读取该条目的第一个本地 PDF。对话中的其他 PDF 附件、多篇选择也会接入。
- 原始文件复制到用户所选对话目录的 `sources/originals/`，带来源标识、修改时间及大小，作为本轮的来源快照。不会改写 Zotero 中的原论文。
- TXT 作为辅助索引保留；来源清单同时给出原文件路径。其他已支持格式也保留原文件，可由实际可用的本地 Skill 或工作区工具处理。
- 页面图像只在模型请求查看时生成，通过原生 Codex 工具返回；不把所有页面预先转为图片。阅读组件和图像在本轮结束后释放。
- 工作区只读模式也可使用内置 PDF 阅读工具。PDF 组件复用 Zotero 10 的 PDF.js，无需用户额外安装 Python、Poppler 或第三方阅读服务。

## 范围与限制

- 需要支持实验性动态工具接口的本机 Codex；旧引擎不支持时会提示更新。仍由使用者自己的 Codex 账号连接模型。
- 图表理解需要支持图片输入的模型。只看了图注或文字索引时，助手不得声称已经看过图像。
- 自动接入的单个原文件最多 80 MB，本轮合计最多 200 MB；手动添加附件仍遵循原有 50 MB 限制。
- 每次工具读取 1–3 页；每轮最多返回 80 页图像，可在下一轮继续。每次搜索最多 100 页，每轮合计最多 600 页；搜索返回下一段页码。
- 页面图像最长边为 2048 像素；细小文字或密集曲线仍可能看不清，不能编造数值。每页文字最多返回 18,000 字，并明确标记截断。
- PDF 在列表中出现表示「可以读取」，阅读依据表示「工具实际返回过这些页」，均不等于全文已读。阅读失败、加密或缺少本地附件时明确返回原因。
- 升级后首次使用旧对话，会开启带 PDF 工具的新原生线程，并用插件中保留的文字历史接续。原聊天记录与旧线程标识保留；旧线程中未存入插件的隐藏状态不会自动迁移。

## 更新与检查范围

从 Zotero「工具 → 插件 → 从文件安装插件」安装 `codex-for-zotero-0.6.5.xpi`，按提示重启，无需卸载旧版。原插件 ID 和对话保存位置不变。

0.6.5 完成 35 项回归检查并核对发行包。本机 Zotero 已实际发送并收到最终回答：Codex 原生 PDF 工具返回第 1 个物理页的完整文字和页面图像，research_pdf_status 核对为文字 1/16、图像 1/16，无工具错误。本轮仅验证第 1 页，不代表模型已读完整篇。 跨模型的实际效果仍需各自确认。


## 0.6.3：完整核读与故障修复

插件现在随包提供独立的 research-pdf-reader Skill，并自动把它交给本机 Codex。Skill 与五个原生工具配套：列出 PDF、搜索、读取文字和图像、补读长页文字、读取覆盖报告。无需到 GitHub 另装 Skill。

优先复用已打开 Zotero 阅读器中的 PDF.js；没有已打开的 PDF 时，使用 Zotero 自己的资源页面加载组件，避免旧版隐藏模块超时。只读原文件副本，不依赖用户预装的 Poppler。

「工具 → 全文图文核读」可把完整核读要求填入输入框，由用户发送。完成前，Codex 应调用 research_pdf_status，回答下显示工具实际返回的正文页数、图像页数、未完整页码和失败。页面文字被截断时可继续补读，不能将文件接入或抽样阅读称为全文读完。无文本层的页单独标记，仍需查看页面图像。

旧对话也能正确显示 Codex 文件引用，点击文件名打开原始 PDF。tmp/pdfs 等临时图片默认折叠，鼠标悬停不再展示遮挡正文的长路径；用户仍可主动清理，更新不自动删除已有临时文件。
