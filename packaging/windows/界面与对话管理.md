# 0.6.0 界面与对话管理

## 阅读布局

聊天、历史、工具、学习、文件固定在顶部。各页内容在中间独立滚动，底部可随时提问。

- 输入区顶部细横条可拖动调整高度；双击恢复自动高度，也能用方向键调整。
- 输入区右上角折叠按钮收起为一行；展开按钮打开大编辑框。
- 任务菜单简化为：对话、生图、对比、科研图、思维导图、学习。
- “资料”菜单管理全文、多篇文献及资料操作；支持原有文件拖拽。
- 保存位置、历史预算、Skill 等统一在右上角设置中。新对话仍需先选择保存目录。
- Token 行显示最近一轮用量，点击看输入/输出、运行时窗口等详情。它不是套餐剩余额度。
- 右上角“•••”包含保存笔记、导出、清理与撤销。

## 复制与文件

鼠标拖选回答后按 Ctrl+C，或右键选择“复制选中文字”。选中文字期间，流式更新会暂缓改写回答区，取消选择后显示最新输出。

新生成的文件显示在对应回答下。点击文件名打开，点击“定位”在资源管理器中定位。图片沿用图片阅读器。Markdown 中的本地文件链接可直接点击；正文或代码中的文件路径使用 Ctrl+点击打开、右键定位，避免正常拖选时误打开。相对路径以该条回答的工作区为准。可执行文件只提供定位，不直接启动。

## 编辑已发送的消息

点击自己消息右上角“编辑”，修改后选“保存并重新生成”。

1. 原版本及其后续回答、文件保留。
2. 顶部出现版本选择器，可随时切回。
3. 新版本只保留编辑点之前的历史，再发送修改后的问题；后续旧回答不会混入。
4. 有可用的原生轮次标识时，从上一个保留轮次 fork；旧版消息缺少标识时新建线程并重建保留的可见历史。
5. 新文件写入独立的 `branches/版本编号/` 目录，旧产物不复制、不覆盖。原附件仍按路径复用。

旧版图片消息没有保存原图路径时，不能自动重发图片，请重新添加图片后发送。调用失败时原版本仍保留，修改后的文本会回到输入框。

## 清理

消息右上角、文件卡旁或“••• → 清理当前对话”进入清单。

- 消息与文件分别勾选。仅删除消息不会自动删除磁盘文件。
- 原论文不进入清单。当前仍在使用的来源副本、其他对话或保留版本引用的文件显示保护原因。
- Windows 回收站：可恢复，暂时不释放磁盘空间。Windows 无法回收时停止并报告，不自动改成永久删除。也可从 Windows 回收站手动恢复。
- 永久删除：必须输入“永久删除”。不支持撤销。
- 可撤销的清理可在“•••”撤销；恢复不覆盖同名新文件。发送新问题、编辑或切换版本后，插件中的上次清理撤销入口失效，Windows 回收站中的文件仍保留。

消息清理只影响插件保存与后续重建的可见历史，不会删除 Codex 自己保存的原生线程。保留版本也会继续占用相应文本和产物空间，受保护的文件不能通过当前版本的清理入口删除。

## 安装与更新

在平常使用的 Zotero 中打开“工具 → 插件”，从文件安装 `codex-for-zotero-0.6.0.xpi`。按 Zotero 提示重启。每人仍需安装并登录自己的 Codex。更新包不包含账号、API Key、你的聊天、论文、Skill 私有内容或签发私钥。

本次只运行源码语法检查、Windows 回收辅助模块编译与安装后的界面查看；没有运行自动化测试，也没有删除你的实际文件或代发新的模型任务。各环境仍需自行确认实际模型与工具可用性。
