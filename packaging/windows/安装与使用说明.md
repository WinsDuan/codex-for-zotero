# Codex for Zotero · 研桥 0.6.5 · Windows 安装与使用

这是一个自定义 Zotero 文献助手插件，通过本机 Codex 连接使用者自己的账号。支持论文对话、图片解读、排版公式与表格、可编辑科研示意图和交互学习包。

**收到 ZIP 后先解压到普通文件夹，再双击「开始这里.html」。不要在压缩包里直接安装或运行。**

## 需要准备什么

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows；已实际验证 Windows x64，其他架构未验证 |
| Zotero | **10.0.x**，当前插件清单只接受这一系列；7/8/9/后续大版本不能承诺兼容 |
| Codex | 本机原生 Windows 版，需要能运行 `app-server`；只有网页或 WSL 版不够 |
| 账号 | 每个人登录自己的 Codex 账号，需要账号有相应使用权限、模型与额度 |
| 网络 | 能正常登录并访问该账号配置的 Codex 服务 |

分享包提供插件和说明，不包含 Zotero、Codex 引擎、账号登录凭据或付费额度。读论文无需安装 Python 或开发环境。选择 npm 安装 Codex 的方式时才需要 Node.js/npm。

## 1. 安装 Zotero 和 Codex

1. 从 [Zotero 官网](https://www.zotero.org/download/) 安装 Zotero，检查“帮助 → 关于 Zotero”中的版本为 10.0.x。
2. 从 [OpenAI Windows 使用说明](https://learn.chatgpt.com/docs/windows/windows-app) 安装原生 Windows 版 Codex，并在当前 Windows 用户下登录自己的账号。已经装好并登录的可直接进入下一步。
3. 双击本包的 **检查环境.cmd**。它会寻找原生 `codex.exe`，显示路径与版本，检查登录状态和 `app-server` 命令，不会调用模型。不要把检查窗口里的个人路径当成通用安装路径发给别人。

### 可选：通过 npm 安装 Codex CLI

在已经安装官方 [Node.js LTS](https://nodejs.org/) 的电脑上，打开一个新的 PowerShell，执行：

```powershell
npm.cmd install -g @openai/codex
codex.cmd login
codex.cmd login status
```

按照浏览器提示登录自己的账号。这里使用 `.cmd` 入口，避免 PowerShell 把 npm/codex 的 `.ps1` 启动脚本误当作需要调整执行策略的文件。若提示权限不足，使用 Node.js/npm 官方支持的当前用户安装方式，或采用 Codex 官方 Windows 安装方式。

安装完成后重启 Zotero，再运行 **检查环境.cmd**。npm 的 `codex.cmd` 是启动包装脚本，**插件的路径设置应填写检查工具找到的真正 `codex.exe`，不能填 codex.cmd**。工具会检查 PATH 中 npm 包装脚本所在目录与常见 npm 全局目录下的 `@openai` 包；自定义目录未找到时可把真实 `codex.exe` 文件拖到检查工具上。

不要单独复制朋友的 codex.exe；官方分发可能需要配套文件。每个人应在自己电脑完整安装。

## 2. 在 Zotero 安装插件

1. 打开 Zotero，点击 **工具 → 插件**。
2. 将解压后的 **codex-for-zotero-0.6.5.xpi** 拖进 Zotero 的插件窗口；也可点齿轮 → **从文件安装插件…**，选择这个 XPI。
3. 确认安装；若 Zotero 提示重启，按提示重启。
4. 插件列表应出现 **Codex for Zotero · 研桥 0.6.5**。XPI 安装在 Zotero 内，不能作为 Edge 扩展安装；不需要解压 XPI，也不需要把文件复制进别人提供的用户配置目录。

## 3. 首次连接

开始提问或添加附件前，先点 **选择保存位置**。插件在所选父目录下建立每条对话的独立子文件夹，保存聊天、附件、原文快照和生成产物；也可主动选“使用 Zotero 默认位置”。已有聊天保留，选择工作区后再继续使用。保存位置绑定当前对话，新对话可另选。

1. 在 Zotero 文献库中选中一篇论文，打开右侧 **研桥** 区域，或点击 **工具 → 研桥文献助手…** 打开大窗口。
   右侧找不到时，点击 Zotero 顶部常驻的 **ChatGPT 标志 + Codex** 按钮，或按 **Ctrl+Alt+C**。它会展开 Codex 面板；没有适合的选中文献时打开独立窗口。
2. 插件会尝试自动连接。成功时显示“**已连接 · ChatGPT**”；其他已有 Codex 服务配置可能显示“已连接 · Codex”。
3. 找不到程序时，点右上角 **⚙**，把检查工具显示的完整 `codex.exe` 路径粘贴到 **Codex 程序路径**，不要加引号，再点击 **保存路径并重连**。
4. 如未登录，使用检查工具给出的 PowerShell 登录命令，在当前 Windows 用户下完成登录，再点击“连接/重连”。
5. 模型先选 **Codex 默认模型**。输入“请先说明你当前拿到了这篇论文的哪些材料，再根据已有材料概括研究问题。”并发送，看到完整回答即完成第一次实际调用。

“检查环境”只检查程序和本地凭据。连接成功也不等于已验证账号额度和所有模型；以实际发送后的结果为准。Codex 桌面版更新后，如原官方安装路径已失效，插件会自动发现新版本并清除失效的固定路径；通常保持程序路径留空即可。自定义路径失效时会单独提示。

## 4. 日常怎么用

### 论文问答、公式和表格

- 选中文献后直接输入问题；**Enter 发送，Shift+Enter 换行**。支持中文输入法。
- 默认提供题录、摘要、笔记和 PDF 批注。需要正文时勾选 **索引全文**：它读取 Zotero 已有的全文索引，并受字数预算限制，不会自动对扫描件做 OCR，也不等于模型已读完整 PDF。
- 标题、加粗、列表、表格和常见 LaTeX 公式会排版显示。公式支持 `\(...\)`、`\[...\]`、`$...$`、`$$...$$`；表格可复制，公式可复制 LaTeX。代码块与不支持的公式仍保留源码。
- 可要求“用表格比较方法，再逐步解释公式”。避免要求把整段回答包在代码块里，这样 Markdown 标记才会正常排版。
- 点 **阅读/输入** 收起或恢复输入区；点 **☷** 显示阅读侧栏；点 **↗** 打开大窗口。
- 顶部快捷入口在文献库和 PDF 标签页中都会保留。Codex 由你手动打开，不自动固定，也不会在启动或新文献中强制选中。升级会一次性清除 0.3.1 留下的 Codex 固定设置；聊天记录仍保存在本地。

### 多个对话、长度与思考强度

- 对话选择框旁的 **＋** 为同一篇文献新建独立对话；**历史** 页面可以搜索和恢复归档对话。⚙ 展开设置后可重命名、归档。
- 每篇默认最多 50 个活跃对话，可调整为 1–200；归档保留记录。
- 新文献对话默认使用 Codex 连续历史，旧对话模式保留；设置中可手动压缩，自动压缩由本机 Codex 按配置管理。限量历史按最近轮数和字数截取，不是自动摘要。
- **连续对话**沿用 Codex 线程的历史，本地轮数/历史字数设置不再截断已有线程上下文。
- 回答长度为“简短/标准/详细”的偏好，不是严格 Token 上限。
- 模型从当前 Codex 实际返回的列表中选择；思考强度只显示该模型支持的档位。选“默认模型”时，可先完成一次调用，或改选具体模型后调节。

### 识别图片

在输入框内点 **＋** 添加图片，或粘贴/拖入图片，输入“请解释这张方法图/实验结果图”。支持 PNG/JPEG/WebP，每次最多 4 张，单张最多 10 MB、合计最多 20 MB。必须选择支持图片输入的模型。

### 使用 Codex 生图与图片阅读器

选择 **图片生成（Codex 工具）**，说明科研图的主题、布局、标注和依据后发送。插件使用本机 Codex 提供方报告的生图能力，只有真正收到图片工具产物才算成功。文字中写“调用 Image 2.5”不等于服务一定使用该版本；当前 RPC 不提供独立的图片模型版本锁定参数，未知模型不会标成 Image 2.5。

点击生成图片或 SVG 预览，可放大、滚轮/滑杆缩放、拖动平移、适应窗口、看原始大小、另存为或附加到文献。0 适应窗口，1 原始大小，＋/－缩放。图片保存到工作区 artifacts/。

### 调用本机 Skill

先选择工作区，在 ⚙ 中点 **读取本地 Skill**，筛选并选择本机 Codex 实际发现的技能，再发送任务。插件使用原生 skill 输入，工具事件可展开查看；完成后进入 **文件** 页刷新产物。普通补充问题由你在选择/输入窗口回答。

工具默认可在当前工作区内运行和写文件，不能默认写到外部，shell 网络默认关闭。Skill 的 Python/Node/绘图库等依赖仍需本机具备；并非每个 Skill 都会自动安装依赖或必然成功。可在 ⚙ 改为只读工具模式。

如 Skill 要输出中文图片，可明确要求“使用可用中文字体，导出后核对缺字与裁切”。部分 Windows 脚本写出的产物会丢失父目录读取权限；插件在生成结束时尝试恢复本轮新产物的权限继承，失败会在文件页提示。

### 添加论文与并排阅读步骤

1. 在当前文献的对话中，点输入区 **＋** 或把文件拖进插件。支持 PDF、DOCX、TXT、Markdown、CSV/TSV、JSON、TeX；旧版 DOC 需先另存为 DOCX。也可把 Zotero 文献条目拖进插件，或点 **加入所选 PDF**。
2. 文档以卡片显示在输入区，并保留在当前对话。最多 8 份，单份 50 MB、合计 120 MB；每轮会按共享上下文预算读取这些文档的提取文字。点 × 从此对话移除。
3. 点 **并排对读 / 对比** 或文件名，在独立窗口选择左右资料、滚动和查找。选中本栏正文后点 **解释选段**，可准备带出处的问题。这里显示提取文字，不保留 PDF / Word 原版式。
4. 点 **让 Codex 比较** 或选择 **文献对比** 任务，检查问题后发送。对比模式会尝试读取主论文正文；模型按来源标签比较研究问题、假设、方法、实验与结论。添加文件和打开对读窗口本身不会发送资料。

PDF 最多提取前 200 页，单份文字最多 400,000 字；被截断、缺少正文等情况会提示。扫描 PDF 需要先 OCR 或上传相关页面图片。DOCX 只提取正文文字，图片/批注未提供，复杂表格和公式可能丢失结构。对比很多长文献时，可在 ⚙ 提高上下文字数上限，但仍应按章节缩小问题范围。

### 科研示意图与思维导图

在任务选择中选 **科研示意图** 或 **论文思维导图**，说明希望呈现的内容并发送。生成后进入编辑器，修改节点与连线的 JSON，应用后可预览并导出 SVG、PNG、JSON，也可将 SVG 附加到论文。每张图最多 32 个节点；适合方法流程、概念关系和论文结构，不是照片/插画生成器。

### 交互学习

选 **交互学习包**，发送“请生成概念卡、实际方法步骤、3 道理解自测题；若材料中有适合简单算式的公式，再加入可调参数演示”。完成后点击 **打开交互学习页**。方法流程可播放/暂停、前后步进、点击节点查看说明与来源；还可展开概念卡、答题反馈、调节公式滑杆、返回对话继续追问或导出 JSON。流程播放不是论文实验仿真；旧学习包中的“动画设计”文字建议重新生成。公式演示只支持受限数学运算，内容不足或关系复杂时省略。滑杆数值是教学假设。

### 多篇比较与保存

- 在 Zotero 文献库中多选，再勾选 **所选多篇**，最多 10 篇，共用文献字数预算；对话仍归属于当前论文。
- 可将最后一条完整回答保存为文献子笔记，或将对话导出为 Markdown。
- **工具**页面提供常用研究提示词，也可保存自定义工具模板。它不是任意第三方脚本或插件的安装器。

## 5. 数据、更新和卸载

- 发送问题时，会将设置范围内的文献材料、当前对话所附文档的提取文字、对话历史和所选图片交给当前 Codex 服务。连接、添加文件和本地并排阅读不会发送论文。
- 工具默认使用当前工作区写入沙箱，也可改为只读；越界操作不会自动批准，shell 网络默认关闭。
- 工作区的 conversation.json 保存聊天；attachments/ 保存文件和提取文本；sources/ 保存文献快照；artifacts/ 保存图片与科研图。Zotero 配置目录中的 codex-for-zotero/conversations.json 保存定位信息及尚未迁移的旧聊天。
- Windows 的常见配置目录位于 `%APPDATA%\Zotero\Zotero\Profiles\` 下；存在多个配置时需确认正在使用哪一个。也可从“帮助 → 调试输出日志 → 查看输出”查看错误；反馈前遮住私人路径与文献内容。
- 这些插件数据是本地文件，不会因为分享安装包而同步给朋友。移除文档会停止将它加入后续请求，暂不自动擦除本地缓存。
- 更新方式：在 Zotero 中安装新版 XPI，按提示重启；更新前关闭 Zotero并备份上述插件数据。此版本没有自动更新服务。
- 卸载方式：在 **工具 → 插件** 中移除 Codex for Zotero · 研桥。卸载不承诺清除本地对话/缓存；需要彻底清理时，先备份并关闭 Zotero，再确认并删除该插件自己的数据目录。

## 6. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 提示插件不兼容 | 检查 Zotero 是 10.0.x。其他系列需要对应适配，修改版本号不能保证兼容。 |
| 右侧没有 Codex | 先选中论文，再点顶部 ChatGPT 标志旁的 Codex 按钮或按 Ctrl+Alt+C。右侧区块可能折叠、移到较下方，或整个详情面板被隐藏。插件列表没有该插件时才需要重新安装。 |
| 换一种方式启动后，连其他插件也不见了 | 检查是否打开了另一套 Zotero 配置。请在平常从桌面打开的 Zotero 内安装 XPI；相同论文库可以对应不同的配置目录和插件列表。 |
| 新文献总是先打开 Codex | 更新到 0.6.5 并重启，升级会清除旧版自动固定设置。之后使用顶部按钮只打开当前 Codex，不自动固定。 |
| 找不到 Codex | 先在 ⚙ 中清空程序路径并保存重连；0.6.5 会自动恢复已失效的官方安装路径。仍失败时运行检查环境.cmd，核对安装位置。 |
| PowerShell 说 npm.ps1/codex.ps1 禁止运行 | npm 安装方式使用文中的 npm.cmd/codex.cmd 命令，无需更改系统执行策略。 |
| 未登录/凭据失效 | 用同一 Windows 用户、同一 Codex 程序登录，再重连；WSL、管理员用户和普通用户的登录状态可能不同。 |
| 有 app-server，但连接失败 | 更新完整 Codex；本插件依赖其协议。检查窗口仅检查命令存在，不能证明所有版本都兼容。保留错误文字反馈。 |
| 429/额度不足/模型不可用 | 检查自己的账号额度、权限与可用模型，换成列表中可用模型；朋友安装本插件不会获得作者的账号或额度。 |
| 一直等待或网络错误 | 先确认官方 Codex 在同一用户下能正常使用，再查看插件报错与本机网络/代理配置。 |
| 没有论文正文或答得很泛 | 选中正确的父级文献，检查摘要、笔记、PDF 批注；按需启用索引全文，确保 PDF 已索引。扫描件需要另行 OCR。 |
| 仍看到很多星号或公式源码 | 检查安装的是 0.6.5 并重开窗口；要求普通 Markdown 和受支持的 LaTeX，不要将整篇回答放在代码块内。复杂宏可能不支持。 |
| 思考强度没有可选项 | 先选具体模型，或完成一次默认模型调用；界面只显示服务返回的真实档位。 |
| 图片被拒绝 | 图片理解请检查格式、数量、体积及模型；图片生成需提供方报告生图能力，并真实返回图片产物。 |
| PDF 没有可读正文 | 扫描件请先 OCR，或上传所需页面图片；加密/损坏文件请先另存为可读取的 PDF。 |
| 旧学习包写着动画但只是说明 | 新增的流程播放器可以逐步播放；如需基于论文方法的步骤，请重新生成学习包。尚未实现的科研仿真不会因文字描述自动出现。 |
| 无法生成图谱/学习包 | 使用对应任务类型；材料需足够，模型需能按结构输出。保留错误后重试或缩小问题范围。 |

## 原始 PDF 自动阅读（0.6.5）

默认自动把当前论文原始 PDF 接入所选工作区。直接提问图表、正文或方法，Codex 可以按需搜索原文件并读取页面文字与图像。无需手动截图；「预载文字」只控制是否提前发送文字索引。设置中可关闭自动原 PDF 阅读。

回答下方的「PDF 阅读依据」列出工具实际返回的页面，点击可回到原文。需要更新本机 Codex 并选择支持图像输入的模型。完整操作、范围与限制见同目录《原始PDF自动阅读.md》。本机 Zotero 已实际发送并收到最终回答：Codex 原生 PDF 工具返回第 1 个物理页的完整文字和页面图像，research_pdf_status 核对为文字 1/16、图像 1/16，无工具错误。本轮仅验证第 1 页，不代表模型已读完整篇。


## 0.6.5 内置全文核读

打开论文后，在「工具」页选择「全文图文核读」，再发送。插件会自动附上内置 research-pdf-reader Skill，无需另外安装；五个 PDF 工具可读取、搜索、查看图像、补读长页文字和报告本轮覆盖范围。回答下查看「正文 x/N · 图像 y/N」，未完整页码会列出。普通问题仍可按需读取相关页。完整说明见《原始PDF自动阅读.md》。
