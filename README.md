## 项目简介

Codex for Zotero 是面向 Zotero 10 的 Windows 文献阅读与研究工作台。它把 Zotero 当前条目的文献上下文、本机 Codex 对话、跨文档阅读和研究产物整理连接起来，让用户可以在阅读论文的同一处提问、比较材料，并继续处理生成的文件。

插件运行在 Zotero 内，通过本机 `codex.exe app-server --listen stdio://` 连接用户已经安装并登录的 Codex。模型、可用思考强度、连续历史以及工具能力取决于本机 Codex 与账号配置。插件不捆绑模型、账号或登录令牌，也不提供单独的模型 API 网关。

### 核心能力

| 能力 | 使用方式 |
| --- | --- |
| 文献上下文问答 | 以当前 Zotero 条目为入口，按设置提供标题、作者、期刊、DOI、摘要、笔记、PDF 批注；可读取已索引全文，或尝试提取本地 PDF 正文。 |
| 对话与资料管理 | 为同一篇文献组织多个对话，搜索和归档历史；添加 PDF、DOCX、文本、表格、JSON、TeX 或图片，也可并排阅读两份材料的提取文本。 |
| 研究辅助工具 | 按可用能力进行图片理解和 Codex 图片生成；调用本机 Codex 原生 Skill；生成可编辑的科研示意图、论文思维导图或交互学习包。 |
| 本地工作区与产物 | 将对话、附件、文献快照及生成文件按工作区整理；预览、编辑图谱、打开或定位产物，并保存笔记或导出 Markdown。 |
| 阅读与表达 | 在回答中呈现 Markdown、表格和 KaTeX 公式；支持回答目录、概念卡、方法步骤、自测题及受限公式参数演示。 |

### 典型工作流

1. 在 Zotero 中选中文献，从右侧 Codex 面板或快捷键打开工作台。
2. 为对话选择保存位置，按需要开启全文、笔记或批注等上下文，并提出阅读问题。
3. 添加其他论文或图片，开展并排阅读和文献比较；也可选择图谱、思维导图或学习包任务。
4. 在本地工作区继续检查和整理结果，编辑图谱，打开生成文件，或将内容保存到笔记和 Markdown。

### 适用条件与数据范围

0.6.0 需要 Windows、Zotero 10.0.x，以及已安装并登录的本机 Codex。当前版本连接 Codex app-server，**尚未内置 DeepSeek API 接入**；图片生成和 Skill 等功能也取决于当前 Codex 提供方、工具及本机依赖是否支持。

对话和工作区文件保存在本机。发送请求时，插件会把配置范围内的文献材料、对话内容和用户选择的附件提交给当前 Codex 服务；额外添加的文件和并排阅读文本由插件在本机处理。实际数据处理还受用户所用 Codex 服务和账号设置约束。

## 打开与使用

右侧入口找不到时，点击 Zotero 顶部常驻的 **插件图标 + Codex** 按钮，或按 **Ctrl+Alt+C**，即可展开右侧 Codex。插件不自动恢复或固定面板，打开新文献时保持 Zotero 的正常侧栏顺序。升级会一次性清除 0.3.1 留下的 Codex 固定设置。

1. 在 Zotero 选中文献，打开右侧 **Codex** 区域；阅读 PDF 时也可以从 **工具 → Codex 文献助手…** 打开大窗口。
2. 首次使用每条对话时，点击 **选择保存位置**，在所选父目录建立独立子文件夹；也可主动选择 Zotero 默认位置。连接成功后显示“已连接 · ChatGPT”，模型可在输入框下方选择。
3. 输入问题后发送。Enter 发送，Shift+Enter 换行。“＋”可添加 PDF、DOCX、TXT/Markdown、CSV/TSV、JSON、TeX 和图片，也支持拖入文件与粘贴图片。
4. 输入框下方可选择 Codex 对话、图片生成、文献对比、可编辑 SVG 科研图、论文思维导图或交互学习包。位图与 SVG 是不同任务。

### 页面与阅读入口

| 入口 | 用法 |
| --- | --- |
| 聊天 | 对当前文献提问；标题、加粗、列表、表格和公式直接排版 |
| 历史 | 搜索不同文献的对话，切换或恢复已归档对话 |
| 工具 | 论文速读、方法拆解、比较文献、审稿视角、图片解读、图谱与学习包；支持保存自己的提示词工具 |
| 学习 | 打开已经生成的学习包，展开概念卡片、理解方法步骤、完成自测、调整公式参数 |
| 对比 | 在独立窗口并排阅读两份材料的提取文本，查找、选段提问或准备比较问题 |
| 文件 | 刷新当前工作区的图片、科研图与 Skill 产物，点击预览或打开 |

### 页面按钮

- **＋**（对话选择框旁）：为同一篇文献创建独立对话。
- **⚙**：历史模式、轮数、字数、回答长度偏好、思考强度滑杆、字号、主题和连接路径；重命名和归档也在展开设置后显示。
- **阅读 / 输入**：收起或恢复输入区，给正文留出更多空间。
- **☷**：显示或收起阅读侧栏，查看回答目录、概念卡片和生成的图谱。
- **↗**：打开更大的独立窗口。

## 对话与上下文

- 每篇文献默认最多 50 个活跃对话，可在设置中调整到 1–200；归档保留记录。
- 新文献对话默认使用 Codex 连续历史；旧对话的模式保留。限量模式按最近轮数和字数重建输入，是截取而不是摘要压缩，默认 12 轮、24,000 字历史。
- “连续对话”由 Codex 保留服务端历史；本地轮数、历史字数限制不再截断已有服务端上下文。旧版对话迁移时保留连续模式和原线程，切换模式时会按可用历史重新建立上下文。
- 连续模式的压缩由本机 Codex 按其配置管理；设置中可手动触发“压缩连续历史”，显示实际压缩事件。界面仅在服务报告后显示运行时窗口，不把官网 API 上限当作本地实际容量。文献字数预算默认 40,000，可调至 2,000,000 字；字数不等于 Token，预算也不保证服务会接受同样大的请求。
- 同一篇 Zotero 论文与其 PDF 附件合并为一个来源；连续线程资料未变时不重复发送全文，原文快照可在工作区 sources/ 中核对。
- 等待时显示已用时间、收到的字数和真实工具事件。本地等待时限默认 30 分钟，可设 1–120 分钟；超时与服务上下文超限分别提示，不自动把超时解释为上下文不足。
- 简短、标准、详细是回答偏好，不是硬性输出 Token 限制。思考强度只列出所选模型实际支持的档位。
- 默认提供标题、作者、期刊、DOI、摘要、笔记、PDF 批注。勾选“索引全文”后读取正文索引；没有索引时尝试提取本地 PDF 文字（前 200 页）。扫描件需先 OCR 或上传页面图片。
- 勾选“所选多篇”可比较 Zotero 当前所选文献，最多 10 篇，共用文献上下文字数预算。
- Token 数只在 Codex 返回实际用量时显示；字数不等于 Token 数。界面按需加载更早的消息，不因显示分页而删除历史。

## 图片、图谱与交互学习

**文档与对比阅读**：把第二篇论文拖入插件，或点输入区“＋”添加；“加入所选 PDF”可将 Zotero 文献库所选条目的本地 PDF 加入此对话。每个对话最多保留 8 份文档，单份 50 MB、合计 120 MB；文档缓存和提取文字随对话保留，移除后不再加入后续请求。每份最多提取 400,000 字，PDF 最多前 200 页。Word 仅提取正文文字，不包含图片、批注或原版式，复杂表格/公式可能丢失结构；不支持旧版 DOC。

点击 **对比 / 并排对读** 或附件文件名，选择左右资料并独立滚动、查找；“解释选段”先在本栏选中文字。对比页展示提取文字，不能代替原 PDF 排版。点“让 Codex 比较”，或选“文献对比”任务后发送，会尝试读取主文献正文，并按共享预算发送当前对话的文档材料，要求逐项标注来源和未读范围。只读到一份资料时会提示添加第二份。

**图片解读**：每次最多 4 张，PNG/JPEG/WebP，单张不超过 10 MB、合计不超过 20 MB。需要支持图像输入的模型。发送时才提交所选图片。

**图片生成**：选“图片生成（Codex 工具）”并发送绘图要求。插件先读取当前提供方是否报告生图能力，接收实际 `imageGeneration` 产物并保存到工作区 artifacts/；没有图片工具结果时不把模型的“已生成”文字判为成功。它沿用本机 Codex 的工具与账号，不另外索取 API key。具体图片模型由工具/服务决定；当前 RPC 没有独立的 Image 2.5 版本锁定参数，不能承诺强制指定 2.5 或拥有 ChatGPT 界面的全部能力。

**图片阅读器**：点击图片或 SVG 预览，支持滚轮/滑杆缩放、拖动平移、适应窗口、原始大小、另存为和附加到文献。键盘 0 适应窗口、1 原始大小、＋/－缩放。

**本地 Skill**：先选工作区，再在 ⚙ 中点“读取本地 Skill”，筛选并选择本机 Codex 实际返回的技能。发送时使用原生 skill 输入，不用同名提示词冒充调用。工具默认可写当前工作区，不能默认写工作区外，shell 网络默认关闭；Skill 的依赖与账号权限仍需满足。模型发来普通补充问题时可在对话框回答；不会自动代填敏感输入。

**科研图 / 思维导图**：选择对应任务或工具卡片，说明希望呈现的研究问题和流程。生成结果可在图谱编辑器中预览、修改节点与连线结构，导出 SVG、PNG、JSON，或将 SVG 附加到当前文献。单张图最多 32 个节点。科研图功能用于方法与关系示意，论文实验数据需来自实际提供的材料。

**交互学习包**：选择“交互学习包”并发送要求。生成后点击“打开交互学习页”。支持概念展开、可播放/暂停/逐步点击的方法流程、单选题即时反馈，以及可调参数的公式演示。流程演示展示学习包中的步骤和连线，不执行模型生成的脚本。旧学习包中的“动画设计”说明不会自动成为特定科研仿真，建议重新生成实际方法步骤。参数演示仅使用受限数学运算；材料不足或公式复杂时会省略。滑杆数值为教学假设，不代表论文实验测量值。

**公式与表格**：公式由本地 KaTeX 转为 MathML，无需联网加载排版组件。支持 `\(…\)`、`\[…\]`、`$…$`、`$$…$$`。不支持的 LaTeX 保留为可复制文本。表格可横向滚动、复制为制表符分隔文本。代码块仍以源码显示。

## 本地数据与升级

- 每次发送会将配置范围内的材料、历史与所选图片提交给当前 Codex 服务，模型可按请求调用本机配置的工具。添加文件与并排阅读在本地处理。
- 开始前可选父目录，每条对话在其下建立 `codex-zotero-文献key-对话id/`。`conversation.json` 保存聊天和学习包；`attachments/` 保存添加文件与提取文本；`sources/` 保存文献原文快照；`artifacts/` 保存图片、SVG 和建议放置的 Skill 产物。工具 cwd 也是该工作区。
- Zotero 配置目录的 `codex-for-zotero/conversations.json` 保存工作区定位信息；未选择工作区的旧聊天仍留在旧目录，选择后迁移所引用的文档与 SVG。工作区选定后绑定当前对话，新对话可重新选位置。移动文件夹后可用“定位原工作区”恢复同一 id，并重定位附件路径。安装包不包含任何聊天或工作区。
- 默认工作区写入沙箱，也可改为只读；需要额外审批的越界操作不会自动批准。移除文档不立即擦除缓存。
- 旧版记录升级前备份为 `conversations.json.v1-backup`；升级不会要求复制或重新分发 Codex 登录令牌。
- 此版本采用手动安装 XPI 更新，尚无自动更新服务。

## 构建与检查

Windows 分享版：运行 `python packaging/build_windows_release.py`，生成包含 XPI、离线教程、环境检查与干净源码的 ZIP。先用 PowerShell 7+ 运行 `./build.ps1` 构建 XPI。打包器只使用代码和允许清单内的文档，不读取用户 Zotero/Codex 配置。

运行 `./build.ps1` 生成 `dist/codex-for-zotero-0.6.0.xpi`。通过 Zotero“工具 → 插件 → 从文件安装插件”安装，按提示重启。

`node --test tests/protocol.test.cjs tests/workbench.test.cjs tests/workspace.test.cjs tests/richtext.test.cjs`：24 项测试覆盖协议、原生图片消息、超时、历史迁移、工作区保存与迁移、中文 Markdown、图谱与公式计算。历史开发文库和包含本机环境信息的原始报告不随公开源码发布。

本机运行环境：Zotero 10.0.6、Codex 0.163.0-alpha.10.2。其他电脑需要各自安装并登录 Codex；具体账号可用模型与额度由其自身配置和服务决定。

第三方排版组件：KaTeX 0.19.0、Marked 15.0.12，均包含对应 MIT 许可证与包来源记录。参考：[OpenAI app-server](https://learn.chatgpt.com/docs/app-server)、[KaTeX](https://katex.org/)、[Marked](https://marked.js.org/)。
